# DALI50
A subset of DALI V2 with syllable-level melody-lyrics alignment annotations, published in the following paper: 

> Changhong Wang, Michel Olvera, and Gaël Richard. "[Melody-Lyrics Matching with Contrastive Alignment Loss](https://www.doi.org/10.1109/TASLPRO.2026.3703164)". _IEEE Transactions on Audio, Speech and Language Processing_, 2026.

The dataset contains melody note - lyrics syllable annotations for 50 songs in the [DALI V2](https://github.com/gabolsgabs/DALI) dataset. The annotations files in `annotations` are named by the song_id, and contain temporal annotations of each syllable.
